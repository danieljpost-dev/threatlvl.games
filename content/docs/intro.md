# Welcome to ThreatLvl Games

ThreatLvl Games provides a comprehensive suite of online tools designed specifically for running and playing 5e-compatible tabletop RPG games. Our platform is built with game masters and players in mind, offering intuitive interfaces and powerful features to enhance your gaming experience.

## What We Offer

Our toolkit includes five core applications:

- **Character Builder** - Create and manage character sheets with full 5e compatibility
- **Dice Roller** - Advanced dice rolling engine with support for complex expressions
- **Encounter Builder** - Design balanced encounters with automatic CR calculations
- **Spell Tracker** - Manage spell slots, prepared spells, and quick references
- **Initiative Tracker** - Track combat with automated turn management

## Key Features

### 🎮 Game Master Tools

- **Encounter Management**: Build balanced encounters using official CR guidelines
- **Initiative Tracking**: Automate combat flow with turn-based management
- **NPC Management**: Quick reference for monsters and NPCs
- **Session Planning**: Organize your campaigns and adventures

### 🧙 Player Tools

- **Digital Character Sheets**: Create and level up characters
- **Spell Management**: Track prepared spells and spell slots
- **Dice Rolling**: Roll with advantage/disadvantage and custom modifiers
- **Inventory Tracking**: Manage equipment, treasure, and magic items

### 🔧 Technical Features

- **Cross-Platform**: Works on desktop, tablet, and mobile devices
- **Real-Time Sync**: Share information with your party in real-time
- **API Access**: Integrate with other tools using our RESTful API
- **Offline Support**: Continue playing even without internet connection
